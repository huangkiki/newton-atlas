# Newton Physics Atlas

Understand Newton Physics through native APIs, physics concepts and versioned source code.

[中文](README.md) · [Sim Atlas home](https://github.com/huangkiki/sim-atlas) · [Introductory guide](docs/guide.md) · [Curriculum](docs/curriculum.md) · [Source map](docs/source-map.md) · [Versions](docs/versions.md) · [Roadmap](docs/roadmap.md) · [Project tracker](https://github.com/users/huangkiki/projects/2)

Part of **Sim Atlas**, an independent community learning series with two complete planned tracks: applications (modeling, control, robotics, sensing and data) and principles/source (dynamics, contact, solvers, integration and extensions).

The initial guide, pinned source map, and [E1: modeling, frames, state and time](docs/modeling-state-time.md) are available in Chinese. E1 covers native construction/import, inertia and unit conventions, state ownership, reset/snapshots, sampling and integration foundations, with a [native API example](examples/e1_model_state.py) and [static validation record](docs/e1-validation.md). A1/A2 are delivered as source-grounded lessons; B0/B4 are only partially covered. The complete course is still in development. This phase prioritizes understanding engine subsystems. The E1 example is syntax checked but unexecuted. Source identity and static checks do not establish runtime or physical correctness. No new simulation campaigns, benchmarks, training or scoring are included; later experimental material will reuse [DexLab](https://github.com/huangkiki/Dexlab) with its original version and workload boundaries.
